# Triskelion public-activities research package

Status: **research-only / no publishable image assets included**

Run date: 2026-10-02 (UTC)

This bounded package records public-source evidence for Tau Gamma Phi blood-donation activities in Zamboanga and the rights decision for candidate photographs. No image was downloaded because no candidate had a documented license or permission from the copyright owner/creator authorizing reuse on the Tau Gamma Phi website. Public visibility, an official-looking page, a courtesy credit, or an original-post URL is not treated as reuse permission.

## Files

- `sources.md` — full-source findings, source status, event facts, and access limitations.
- `rights-notes.md` — rights review and exact permission needed before download/use.
- `approval-needed.md` — bounded handoff list with original links/embed alternatives.
- `image-manifest.csv` — schema-complete manifest; zero selected images.
- `image-manifest.json` — JSON manifest; zero selected images.

No frontend, public/static, application, test, config, Git, or deployment files were changed. No image originals or optimized derivatives are present in this directory.
